BETTER CONTROL V13 MULTIÁREA
============================

1. Ejecuta SQL_V13_PASO_8_SOPORTE_FRONTEND.sql en Supabase.
2. Sube/reemplaza en GitHub TODO el contenido de esta carpeta en la raíz del repositorio.
3. Conserva config.js con tu URL y publishable key actuales.
4. Haz Ctrl+F5.

Incluye:
- detección de usuario, área y rol con mi_perfil_crm()
- RH / CPRO / Enlace / Mesa separados
- Ingrid GLOBAL con selector de área
- supervisoras pueden finalizar tareas de su área
- finalizada_por y finalizada_por_supervisor
- buscador de actividades
- catálogo de actividades por área
- ranking únicamente del día
- administración ASISTENCIA/Tiendas visible solo para Mesa
- nubes animadas, GIF cute y corazones al finalizar
- evidencias nuevas guardadas bajo carpeta por área

IMPORTANTE:
- Los datos históricos no se borran.
- Las actividades inactivas antiguas siguen disponibles para el historial.
- La vista GLOBAL de Ingrid es de consulta; no registra actividades como integrante de un área.
