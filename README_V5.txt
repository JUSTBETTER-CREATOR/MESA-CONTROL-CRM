MESA DE CONTROL CRM V5 - MULTIPLES ACTIVIDADES

Cambios:
- Una analista puede iniciar más de una actividad al mismo tiempo.
- Cada actividad EN CURSO aparece como tarjeta independiente en Inicio.
- Cada tarjeta propia tiene su botón "Finalizar actividad".
- El botón de la pantalla Nueva actividad finaliza la actividad más reciente si se usa.
- No requiere cambios SQL nuevos.

Para actualizar GitHub:
1. Reemplaza app.js, index.html y styles.css con los de esta carpeta.
2. Conserva tu config.js actual si ya está funcionando.
3. Espera a que GitHub Pages publique.
4. Haz Ctrl+F5.
