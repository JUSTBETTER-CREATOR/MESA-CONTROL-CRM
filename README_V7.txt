V7 - ANUNCIOS COMPARTIDOS

1. Ejecuta SQL_PASO_6_ANUNCIOS.sql en Supabase > SQL Editor.
2. En GitHub reemplaza index.html, app.js y styles.css.

5. MARIELA puede cerrar un anuncio con la X; no se borra, solo pasa a activo=false.
6. Los anuncios se actualizan en tiempo real.
